# Windows executable

Download [MusicPlayer.exe](MusicPlayer.exe) using GitHub's **Download raw file**
button. Run it on Windows 10/11, 64-bit. Python installation is not required.

The full Python source is in the repository root. Use GitHub's **Code → Download
ZIP** to download the source, executable, instructions, and license notices together.
There are no committed ZIP files in this repository.

The executable is unsigned. Company device policy may require IT approval.
See the root README for usage, and THIRD_PARTY_NOTICES.md / third_party/ for
license notices to retain when redistributing the application.

Validation: 13 tests passed on Linux and Windows Python under Wine; the packaged
EXE passed playback/persistence and normal launch/shutdown checks under Wine.
Native Windows CI status is shown in the repository's Actions tab.
